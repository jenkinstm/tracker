# Контекст проекта

Что уже решено, чтобы не переобсуждать. Полные требования — в `spec.md`.

## Принятые решения

| Вопрос | Решение | Почему |
|---|---|---|
| Пользователи | Один аккаунт, регистрации нет | Личный инструмент. Вход по паролю из `.env` |
| База продуктов | Свой сид ~300 позиций + Open Food Facts как запасной поиск | Сид точнее и покрывает 90% реальной еды; OFF добирает магазинные бренды |
| Стек | TypeScript целиком | Один язык на фронт и бэк, общие типы и расчёты в `packages/shared` |
| Хостинг | Свой VPS, поддомен `fit.profkosm.ru`, Caddy + Let's Encrypt | HTTPS нужен для Web Push, камеры и PWA |
| Тренировки | Логирование по подходам, а не одно поле «рабочий вес» | Без подходов не видно прогрессии. Скорость компенсируется предзаполнением (FR-5.4) |
| Импорт из прототипа | Не нужен, старт с нуля | Накопленных данных нет |
| Тип приложения | PWA, устанавливается на домашний экран | Нативные приложения не пишем |

## Ключевая идея, которую нельзя потерять

Приложение отличается от обычного дневника разделом 3.6 ТЗ: оно сверяет
«сколько ел» с «сколько сбросил», считает фактический TDEE и предлагает
скорректировать норму калорий. Всё остальное — стандартный дневник, который
существует в десятке приложений. Если при планировании придётся чем-то жертвовать,
жертвуем не этим.

Заполняются при первом запуске, редактируются в настройках:

белок           160 г

окно питания    12:00–20:00
шаги            9000

часовой пояс    Europe/Moscow

## Сид упражнений

Домашний инвентарь: гантели, штаба, мешок, гиперэкстензия, резинки, фитбол.
Упражнения на тренажёрные залы в сид не добавляем — их можно завести вручную.

Три программы по умолчанию:

- **A:** гоблет-присед, жим гантелей лёжа, тяга гантели в наклоне, гиперэкстензия, планка
- **B:** румынская тяга, жим гантелей стоя, тяга штанги в наклоне, выпады, пресс
- **C:** приседания со штангой, отжимания с возвышения, тяга резинки к лицу, ягодичный мостик, работа с мешком

## Сид продуктов

~300 позиций русской домашней кухни: мясо и птица, рыба, молочное, крупы и гарниры,
овощи, фрукты, масла и орехи, хлеб, сладкое. КБЖУ на 100 г **готового** продукта
(варёная гречка, а не сухая) — это частый источник ошибок в трекерах.
У каждой позиции — типичная порция в граммах для быстрого добавления.
Сладкое помечается флагом `is_sweet` — оно считается в отдельный подбюджет.

## Формулы, которые надо реализовать точно

```
BMR (Миффлин–Сан Жеор, муж) = 10×вес + 6.25×рост − 5×возраст + 5
TDEE                        = BMR × коэффициент активности
тренд веса                  = скользящее среднее за 7 дней + EMA (α = 0.25)
темп, кг/нед                = линейная регрессия по последним 21 дню × 7
                              (не считать при менее чем 4 замерах)
прогноз даты                = (тренд − цель) / |темп| недель от сегодня
TDEE фактический            = средние ккал за 14 дней
                              + (Δтренда за 14 дней в кг × 7700 / 14)
1ПМ (Эпли)                  = вес × (1 + повторы / 30)
```

Целевой коридор снижения: 0.5–1.0% массы тела в неделю. Выход за коридор три недели
подряд — повод предложить пересчёт нормы. Приложение **предлагает**, а не меняет само.

Рекомендация не выдаётся, если полнота дневника за период ниже 80% — иначе она
построена на неполных данных и будет вредной.
