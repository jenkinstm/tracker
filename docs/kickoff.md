Скопируй текст ниже целиком и отправь первым сообщением после `claude` в папке проекта.

---

Прочитай `CLAUDE.md`, `docs/spec.md`, `docs/context.md` и `docs/roadmap.md`.

Начинаем с блока 1 из roadmap — скелет проекта. Задача:

1. Монорепозиторий: `apps/web` (React + TypeScript + Vite), `apps/api`
   (Fastify + Prisma), `packages/shared` (общие типы и расчётные функции).
   Менеджер пакетов — pnpm с workspaces.
2. `docker-compose.yml` для локальной разработки: postgres:16 с расширением
   `pg_trgm`, приложение, тома для данных.
3. Prisma-схема по разделу 5 ТЗ, целиком, со всеми таблицами и индексами.
   Первая миграция.
4. Вход по паролю (FR-1.0): argon2id, httpOnly-cookie на 90 дней, rate limiting
   5 попыток за 15 минут. Плюс скрипт `pnpm hash-password` для генерации хеша
   в `.env`.
5. Пустой главный экран за авторизацией и страница входа. Верстать красиво пока
   не нужно — важно, что маршрутизация и сессия работают.
6. Vitest настроен, один тест-заглушка в `packages/shared` проходит.

Перед тем как писать код, покажи план: структура папок, список файлов, содержимое
Prisma-схемы. Особенно внимательно — схема БД: её переделывать потом дорого,
я хочу посмотреть до первой миграции.

Готовность блока проверяю так: `docker compose up`, вход по паролю, перезагрузка
страницы не разлогинивает, `pnpm test` зелёный.
